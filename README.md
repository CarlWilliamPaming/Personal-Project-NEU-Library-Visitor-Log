# NEU Library Visitor Log System  
### Smart Digital Logging for a Modern Library

---

## Live System  
👉 https://midterm-neu-library-log.netlify.app  

---

##  Overview  
This system showcases a modern web-based solution for managing library visitor logs at New Era University. Built with a focus on usability, performance, and clean UI design, it provides a seamless check-in experience for users while giving administrators full control over records and monitoring.

The interface follows a kiosk-style workflow, ensuring fast interaction, minimal input, and a smooth user journey across all devices.

---

## Authentication  
- Google Login (Gmail / NEU Email)  
- Manual Entry for guests  
- Admin access (restricted emails only)  

---

## Features  

### Visitor  
- Quick Check-in via Google Login
- Smart detection for returning users
- Simplified form for repeat visitors
- Purpose-based visit logging
- Real-time confirmation after submission

### Admin  
- Secure dashboard access (restricted emails)
- Visitor records management
- Block / Unblock user accounts
- Live search filtering (instant results)
- Export and reporting tools

---

## Access Control  
- Blocked users are denied immediately after login  
- Popup notification is shown  
- No further access until unblocked  

---

## Tech Stack  
- HTML, CSS, JavaScript  
- Supabase (Auth + Database)  
- Netlify (Deployment)
